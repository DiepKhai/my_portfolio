# Portfolio Cá Nhân - Diệp Khai

Chào mừng đến với website Portfolio cá nhân của mình. Đây là nơi mình trưng bày các dự án và kỹ năng lập trình.

## 🚀 Live Demo
👉 **Xem website tại đây:** [https://DiepKhai.github.io/my_portfolio/](https://DiepKhai.github.io/my_portfolio/)

## 🛠 Công nghệ sử dụng

### Core Technologies
* **React** v16.13.1 - Thư viện JavaScript để xây dựng giao diện người dùng
* **React Scripts** v3.4.3 - Công cụ build và development từ Create React App

### UI Libraries & Components
* **Bootstrap** v4.5.2 - Framework CSS responsive
* **React Bootstrap** v1.3.0 - Bootstrap components cho React
* **React Vertical Timeline Component** v3.3.1 - Timeline cho phần Experience
* **React Awesome Slider** v4.1.0 - Image slider cho project gallery
* **React Switch** v5.0.1 - Toggle switch cho dark/light theme
* **React Typical** v0.1.3 - Typing animation effect

### Styling
* **SASS/SCSS** v1.42.1 - CSS preprocessor
* **Google Fonts** (Raleway) - Custom typography
* **Font Awesome** - Icons

### Additional Features
* **jQuery** v3.5.1 - DOM manipulation và utilities
* **React GA** v3.1.2 - Google Analytics integration
* **@iconify/react** v1.1.3 - Icon library cho skills section

### Development & Deployment
* **gh-pages** v3.1.0 - Deployment lên GitHub Pages
* **@testing-library** (Jest DOM, React, User Event) - Testing utilities
